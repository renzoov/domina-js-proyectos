# Generador de paletas: el proyecto terminado

Abre `index.html` con doble clic en tu navegador. No hace falta instalar nada.

- La barra espaciadora (o «Generar») crea una paleta nueva.
- «Fijar» deja un color quieto. `Ctrl + Z` y `Ctrl + Y` deshacen y rehacen.
- «Exportar» da las variables CSS, y «Desde una foto» saca la paleta de una imagen.

`app.js` está ordenado como la guía: cada parte va entre `// PASO n` y `// FIN PASO n`.
Una línea que termina en `// PASO n` se agrega en ese paso, dentro de código anterior.

Guía paso a paso: https://domina-js.pages.dev/proyectos/generador-de-paletas

## Llévalo más lejos

- Nombres de colores: muestra en cada chip el nombre del color más cercano de una lista.
- Paletas favoritas, guardadas en `localStorage`.
- Fijar con el teclado: las teclas 1 a 5 fijan o sueltan cada color.
