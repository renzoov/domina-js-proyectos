# Generador de paletas: el punto de partida

El HTML y el CSS ya están hechos. Tú escribes el JavaScript en `app.js`, paso a paso,
siguiendo la guía: https://domina-js.pages.dev/proyectos/generador-de-paletas

Así queda cuando lo terminas: https://domina-js-proyectos.pages.dev/01-generador-de-paletas/final/

Cada paso tiene su lugar en `app.js`, entre `// PASO n` y `// FIN PASO n`.

Para verlo, abre `index.html` con doble clic en tu navegador.
