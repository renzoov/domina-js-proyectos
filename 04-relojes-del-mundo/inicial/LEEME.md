# Relojes del mundo: el punto de partida

El HTML y el CSS ya están hechos. Tú escribes el JavaScript en `app.js`, paso a paso,
siguiendo la guía: https://domina-js.pages.dev/proyectos/relojes-del-mundo

Así queda cuando lo terminas: https://domina-js-proyectos.pages.dev/04-relojes-del-mundo/final/

Cada paso tiene su lugar en `app.js`, entre `// PASO n` y `// FIN PASO n`.

Para verlo, abre `index.html` con doble clic en tu navegador.
