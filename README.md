# Proyectos de domina-js

30 aplicaciones completas para construir **solo con JavaScript**, de la más fácil al proyecto final. Son la sección «Proyectos» de [domina-js](https://domina-js.pages.dev), el curso gratuito de JavaScript en español.

El HTML y el CSS de cada proyecto ya vienen hechos. Tú escribes el JavaScript paso a paso, siguiendo la guía de cada uno en el sitio, con pistas y la solución.

## Los proyectos

| N.º | Proyecto | Nivel | Guía | Demo |
|---|---|---|---|---|
| 1 | [Generador de paletas](01-generador-de-paletas/) | Fácil | [Guía](https://domina-js.pages.dev/proyectos/generador-de-paletas) | [Pruébalo](https://domina-js-proyectos.pages.dev/01-generador-de-paletas/final/) |
| 2 | [Temporizador Pomodoro](02-pomodoro/) | Fácil | [Guía](https://domina-js.pages.dev/proyectos/pomodoro) | [Pruébalo](https://domina-js-proyectos.pages.dev/02-pomodoro/final/) |
| 3 | [Reto de mecanografía](03-mecanografia/) | Fácil | [Guía](https://domina-js.pages.dev/proyectos/mecanografia) | [Pruébalo](https://domina-js-proyectos.pages.dev/03-mecanografia/final/) |

Cada demo está en `domina-js-proyectos.pages.dev/<carpeta>/final/`. Los demás proyectos se publican de a uno. La lista completa está en [domina-js.pages.dev/proyectos](https://domina-js.pages.dev/proyectos).

## Qué hay en cada carpeta

```text
01-generador-de-paletas/
├── README.md     de qué se trata, la demo y la guía
├── inicial/      el punto de partida: HTML y CSS completos, y un app.js con un comentario por paso
└── final/        el proyecto terminado, para comparar o para ver cómo queda
```

## Bajar un solo proyecto

Desde la guía de cada proyecto puedes descargar sus zips. También puedes bajar una carpeta sin clonar todo el repositorio:

```sh
npx degit renzoov/domina-js-proyectos/01-generador-de-paletas/inicial mi-paleta
```
