# Notificaciones toast: el punto de partida

El HTML y el CSS ya están hechos. Tú escribes el JavaScript en `zona-toasts.js`, paso a paso,
siguiendo la guía: https://domina-js.pages.dev/proyectos/notificaciones-toast

Así queda cuando lo terminas: https://domina-js-proyectos.pages.dev/08-notificaciones-toast/final/

Cada paso tiene su lugar en `zona-toasts.js`, entre `// PASO n` y `// FIN PASO n`.

Este proyecto usa módulos (import y export), y el navegador no los carga si abres
`index.html` con doble clic. Ábrelo con un servidor local: en VS Code, instala la extensión
Live Server, haz clic derecho en `index.html` y elige «Open with Live Server».
