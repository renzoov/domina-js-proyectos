# Explorador con scroll infinito: el punto de partida

El HTML y el CSS ya están hechos. Tú escribes el JavaScript en `app.js`, paso a paso,
siguiendo la guía: https://domina-js.pages.dev/proyectos/explorador-de-arte

Así queda cuando lo terminas: https://domina-js-proyectos.pages.dev/06-explorador-de-arte/final/

Cada paso tiene su lugar en `app.js`, entre `// PASO n` y `// FIN PASO n`.

Para verlo, abre `index.html` con doble clic en tu navegador.
